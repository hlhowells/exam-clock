Exam Clock: how to use it

For exams officers and invigilators.

1. Before the exam (on your laptop)

  1. Open the Exam Clock library and click + New display.
  2. Fill in the date, centre name and number, room and any notes for the bottom of the screen.
  3. For each exam, enter the subject, board, paper code, planned start and duration.
  4. Each exam has a list of finish times. By default there is a normal finish and an extra time (+25%) finish. On screen these are labelled Finish and Extra time; the percentage is shown only when an exam has more than one extra time finish. Add +50%, +100% or any other percentage you need. Tick Rest breaks on a finish time for candidates who have supervised rest breaks: they get their own Start/End rest break button on the day.
  5. Check the preview on the right. Extra time finishes are rounded up to the next whole minute (e.g. 1h 30m + 25% = 1h 53m).
  6. Click Link & QR code for the exam screen and send the link to the smartboard (see section 2).

Creating many displays at once from a spreadsheet

  1. In the library, click Create displays from CSV, then Download template.
  2. Open the template in Excel and fill in one row per exam: Display, Date, Room, Subject, Board, Paper code, Start, Duration, Extra time, Rest breaks. Only Start and Duration are required.
    • Rows with the same Display name and date go on one screen. Leave Display blank to group exams by date, room and morning/afternoon automatically.
    • Extra time: percentages, e.g. 25, or 25;50 for two extra time finishes. Rest breaks: e.g. 0 or 25.
  3. Save it as CSV UTF-8 (File → Save As), then choose the file. Check the preview, fix any rows it lists as skipped, and click Create displays.
  4. Importing a display with the same name and date as an existing one replaces it, so you can re-import an updated timetable.

Export links (top of the library) downloads a spreadsheet listing every display’s name, date, room, exams and link. It’s handy for sharing with invigilators or keeping with the exam timetable. To open a display, copy its link from the spreadsheet into a browser.

Everything saves automatically in your laptop’s browser. Use Export library now and then to keep a backup file. If you edit a display after sending its link, send the new link: the link contains the whole exam setup.

2. Getting it onto the smartboard

Any of these will work:

  • Email the link to yourself and open it in the smartboard’s browser. Bookmark it, e.g. “Mon AM Sports Hall”.
  • Paste the link into a shared document (OneDrive, Google Drive, Teams) that you can open on the smartboard.
  • Open the library on the smartboard itself, Import your exported library file, then choose a display and press Open the display here.

3. On the day

  1. Open the display link on the smartboard. Tap the full screen button in the bottom-left corner.
  2. Check the clock matches the hall clock or your phone.
  3. When you say “you may begin”, tap the green Start all exams button under the clock and confirm. Every exam’s start time is set to the next whole minute and the button disappears. If you have already started some exams from the controls, it says Start remaining exams.
  4. To open the invigilator controls, press and hold the lock in the bottom-right corner for one second. A quick tap does nothing, so candidates can’t change anything by accident.

If the page is reloaded or the smartboard restarts, open the same link again: start times, breaks and pauses from today are remembered on that smartboard.

4. Smartboard set-up checklist (do this once)

A web page cannot stop the smartboard’s own power saving. Please check these settings in the panel’s settings menu.
  • Sleep / screen off / eco mode: turn off, or set longer than your longest exam session.
  • Date & time: set to automatic (network time) and the UK time zone, so the clock is accurate.
  • Browser: open the Exam Clock once while connected to the internet so it is saved for offline use.
  • Test: leave a display running for a full session length before the real exam season.

5. Troubleshooting

  • “Check: this display was set up for …” appears when the display’s date isn’t today. Times are still shown for today; check you opened the right link.
  • Text is too small with many exams: the text shrinks to fit everything. Split exams across two displays if needed.
  • The link doesn’t open on the smartboard: make sure the whole link was copied (it is long).
