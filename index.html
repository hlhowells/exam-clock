Show this display on the exam screen

You are running the library from a file on this computer, so this link only works on this computer. Put Exam Clock on a website (see the README) to get links that work on the smartboard.

  1. Send the link to the smartboard: email it to yourself, or paste it into a shared document, then open it in the smartboard’s browser.
  2. Bookmark it on the smartboard so it’s ready on the day.
  3. Or scan the QR code with a phone or tablet.
