Show this display on the exam screen

You are running the library from a file on this computer, so this link only works on this computer. Put Exam Clock on a website (see the README) to get links that work on the smartboard.

  1. Send the link to the smartboard: email it to yourself, or paste it into a shared document, then open it in the smartboard’s browser.
  2. Bookmark it on the smartboard so it’s ready on the day.
  3. Or scan the QR code with a phone or tablet.

Create displays from a CSV file

Put one exam on each row of a spreadsheet and save it as CSV (in Excel: File → Save As → CSV UTF-8). Rows with the same Display name and date go on the same screen. If you leave Display blank, exams are grouped by date, room and morning/afternoon.

Columns you can use
ColumnWhat to put
DisplayOptional. A name for the screen, e.g. Tue 18 May AM – Sports Hall.
Datee.g. 18/05/2027
Roome.g. Sports Hall
Subjecte.g. Mathematics Paper 1 (Higher)
Board, Paper codeOptional, e.g. AQA, 8300/1H
Start *24-hour time, e.g. 09:00
Duration *Minutes (90) or hours:minutes (1:30)
Extra timeExtra time percentages, e.g. 25 or 25;50. Leave blank for none. Without this column, +25% is added to every exam.
Rest breaksPercentages for finish times with rest breaks, e.g. 0 (no extra time) or 25. Leave blank for none.
Notes, Centre, Centre numberOptional. Taken from the first row of each display.

* required. Column headings can be in any order. A normal finish time is always included.
